## Load order is load-bearing

Vanilla ES5-ish JS, no bundler, no npm, no build step. Modules are loaded
by `<script src>` in this exact order and **must not be reordered**:

  1. `src/stages.js`
  2. `src/tiles.js`
  3. `src/hazards.js`
  4. `src/sim-core.js`
  5. `src/render/iso.js`
  6. `src/scenery.js`
  7. `src/render/scene.js`
  8. `src/roster.js`
  9. `src/render/sprite.js`
  10. `src/render/deathfx.js`
  11. `src/render/character.js`
  12. `src/main.js`

Adding a module means editing **both** `index.html` and `MODULES` in
`tools/playtest.py`, or the headless gate will not see it.

## Rendering

  context : `getContext("2d")`
  dpr     : device-pixel-ratio scaled transform (see src/main.js)

**This is an isometric 2D canvas renderer. It is not 3D.** `Iso.projectS()`
returns `[x, y]` — two numbers. A `.glb` cannot be drawn here. Before
importing any 3D asset, run:

```
python3 /Users/mac/.minimax/asset-library/tools/gamekit.py doctor .
```

## Hazard art is drawn procedurally

No sprite files. `src/hazards.js` defines `KINDS` (car, taxi, log, train,
bird, pit, geyser, sinkhole…) and `src/render/scene.js` draws them with
canvas paths. Adding a new vehicle means editing `KINDS`, not dropping in
an image.

## Where to get more art

**`/Users/mac/.minimax/asset-library/`** — 114,852 indexed 2D images and
1,909 3D models. Query it:

```
L=/Users/mac/.minimax/asset-library
python3 $L/tools/gamekit.py doctor .        # what can this renderer show?
python3 $L/tools/image_search.py <terms>
python3 $L/tools/gamekit.py sheet scenery  # contact sheet of real pictures
```

**Licensing:** all 114,852 2D records are `unverified` — do not
redistribute. 29 of 30 top-level packs are CC0-1.0 or MIT and are safe to
ship. Four user-supplied archives are excluded entirely; that is a rights
decision for the owner, not for an agent.

**Do not generate placeholder art** when the library holds something
suitable. Report "not in library" instead — that is a better outcome than
a pretty wrong answer.

## Before you commit

```
python3 tools/playtest.py 10
```

Requires `RESULT: NO ERRORS`, `24/24` sprites resolved, `main.js booted`,
and a **non-zero** forward-only clear rate. A zero there means a lane has
become unclearable.
