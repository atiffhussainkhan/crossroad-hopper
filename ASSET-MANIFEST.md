# Legacy fallback asset inventory

> Generated by `tools/build_asset_manifest.py`. **Do not hand-edit** —
> regenerate with `python3 tools/build_asset_manifest.py`.
> This inventories the older canvas fallback and retained reference images.

The primary game now renders live 3D models with vendored Three.js.
For current asset mapping read [`assets/models/manifest.json`](assets/models/manifest.json),
[`docs/ASSET-SELECTION.md`](docs/ASSET-SELECTION.md), and
[`MINIMAX-HANDOFF.md`](MINIMAX-HANDOFF.md). All shipped model dependencies
and licences are included; the external library is not needed to play.
Do not regenerate artwork or rerun imports for an as-is migration.

## Load order is load-bearing

Classic simulation/fallback scripts load in this order and must not be reordered.
There is no build step. Serve over HTTP for the native 3D modules and glTF files.

  1. `src/stages.js`
  2. `src/tiles.js`
  3. `src/hazards.js`
  4. `src/sim-core.js`
  5. `src/render/iso.js`
  6. `src/scenery.js`
  7. `src/render/scene.js`
  8. `src/roster.js`
  9. `src/render/sprite.js`
  10. `src/render/deathfx.js`
  11. `src/render/character.js`
  12. `src/main.js`

Classic module additions must also update the `MODULES` list in `tools/playtest.py`.
Native WebGL modules are separate from that classic headless bundle:
- `src/render/world3d.js`

## Legacy fallback rendering

  context : `getContext("2d")`
  dpr     : device-pixel-ratio scaled transform (see src/main.js)

`Iso.projectS()` belongs to the canvas fallback. The primary scene is
`src/render/world3d.js`, which loads glTF/GLB through the included Three.js loader.
For static renderer evidence, run:

```
python3 tools/gamekit-agent/gamekit.py doctor .
```

## Legacy procedural hazard art

`src/hazards.js` owns hazard kinds and collision. `src/render/scene.js`
draws the canvas fallback; `src/render/world3d.js` uses the selected models.
New kinds need consistent simulation, model-manifest and fallback support.

## Where to get more art

An existing external library can be configured for optional asset discovery.
See `tools/gamekit-agent/QUICKSTART.md`; it is not a game runtime dependency.

```
python3 tools/gamekit-agent/gamekit.py status
python3 tools/gamekit-agent/gamekit.py search tree
```

**Licensing:** library records can be unverified; check each selected file.
The shipped 3D selection retains CC0/MIT notices in `assets/models/licenses/`
and per-file hashes/source evidence in `assets/models/provenance.json`.

**Do not generate placeholder art** when the library holds something
suitable. Report "not in library" instead — that is a better outcome than
a pretty wrong answer.

## Before you commit

```
bash tools/run_all.sh
python3 tools/playtest.py 10 --seed 12345
```

Requires `RESULT: NO ERRORS`, `24/24` sprites resolved, `main.js booted`,
and a **non-zero** forward-only clear rate. A zero there means a lane has
become unclearable.
Real browser inspection separately verifies 3D lighting, clipping and animation.
